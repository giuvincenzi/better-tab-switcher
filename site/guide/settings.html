To open the settings, click All settings in the switcher's toolbar. Every change is saved automatically, so there is no Save button.

Appearance

  • Theme: the colors of the switcher and of the settings page. Device theme (the default) follows your computer's light or dark mode. You can also choose Light or Dark.
  • View: List (the default) or Grid. See List and grid.
  • Show toolbar: the bar at the top of the switcher, with the search field and buttons for the view and the settings. On by default.

With the list, you also see:

  • Compact: shorter rows, so more tabs fit. On by default.
  • Tabs shown before scrolling: 6, 10 (the default), 15, or Fit the screen, which shows as many as the screen's height allows.

With the grid, you see this instead:

  • Show: Previews (the default) shows a picture of each tab, and Icons shows only each site's icon.

Switching

  • Show tabs from: This window (the default) or All windows. With all windows, each tab from another window shows its window's number.
  • Show pinned tabs: when off, the switcher leaves out pinned tabs, except the one you are on. On by default.
  • Delay before the switcher appears: if you press and release the shortcut quicker than this, you switch to the previous tab without seeing the switcher. From 0 to 1000 milliseconds, 50 by default. At 0, the switcher appears right away.
  • Stay open until you choose a tab: letting go of the shortcut's keys doesn't switch tabs. You choose a tab with Enter or a click. Off by default.
  • Open the switcher in a window on Chrome's pages (in Microsoft Edge, Open the switcher in a window on Microsoft Edge's pages): where the browser doesn't let extensions in, the switcher opens in a small window of its own. On by default. See The switcher's own window.
  • Auto-select: the selected tab opens by itself after a few seconds, and a line shows the time left. Off by default.
  • Auto-select time: how many seconds Auto-select waits, from 1 to 10, 3 by default. You can change it only when Auto-select is on.

Tab details

  • Website address: the site's address on each tab. Off by default.
  • Long website addresses: Cut short with “…” (the default), or Scroll on the selected tab to show them whole. You can change it only when Website address is on.
  • Pinned tab icon: on by default.
  • Playing audio icon: on by default.
  • Inactive tabs: tabs the browser has unloaded to save memory get an icon and are shown in grey. On by default.
  • Tab group color: on by default.
  • Last used: how long ago you used each tab, like “15 min ago”. Off by default.

Keyboard shortcuts

This section shows the keys for Next tab (Alt+S by default) and Previous tab (Alt+Shift+S by default). When a shortcut has no keys, it says Not set. The Change shortcut button opens the browser's page where you change them: see Change the keys. The How to use Ctrl+Tab link opens Use Ctrl+Tab.

Reset

Under Restore default settings, the Restore button puts every setting back to its default at once. It doesn't change your keyboard shortcuts, which the browser manages.
