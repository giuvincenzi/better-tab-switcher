To open the settings, click All settings in the switcher's toolbar. Every change is saved automatically, so there is no Save button.

The sidebar on the left lists the sections, each with its icon, and the page shows the one you choose. System and About are last, under a line. The page's address keeps it, so reloading the page or going back shows the same section. In a narrow window, the sections are behind the Main menu button at the top left.

Search settings

Type in Search settings, at the top of the page, to find a setting in any section. The page then shows only the settings whose name, description or choices have what you typed, with the matching text highlighted, grouped by their section. When a section's name matches, it shows whole. The × button or Esc clears the search, and choosing a section in the sidebar clears it too.

Some settings apply only while another one is on, like Auto-select time with Auto-select. They are shown indented under it, and only while it is on. A search finds them even while it is off: they are then shown faded, and you can't change them until you turn it on.

Appearance

  • Theme: the colors of the switcher and of the settings page. Device theme (the default) follows your computer's light or dark mode. You can also choose Light or Dark.
  • View: List (the default) or Grid. See List and grid.
  • Show toolbar: the bar at the top of the switcher, with the search field and buttons for the view and the settings. On by default.

With the list, you also see:

  • Compact: shorter rows, so more tabs fit. Off by default.
  • Tabs shown before scrolling: 6, 10 (the default), 15, or Fit the screen, which shows as many as the screen's height allows.

With the grid, you see this instead:

  • Show: Previews (the default) shows a picture of each tab, and Icons shows only each site's icon.

Switching

  • Show tabs from: This window (the default) or All windows. With all windows, each tab from another window shows its window's number.
  • Delay before the switcher appears: if you press and release the shortcut quicker than this, you switch to the previous tab without seeing the switcher. From 0 to 1000 milliseconds, 50 by default. At 0, the switcher appears right away.
  • Stay open until you choose a tab: letting go of the shortcut's keys doesn't switch tabs. You choose a tab with Enter or a click. Off by default.
  • Open the switcher in a window on Chrome's pages (in Microsoft Edge, Open the switcher in a window on Microsoft Edge's pages): where the browser doesn't let extensions in, the switcher opens in a small window of its own. On by default. See The switcher's own window.
  • Auto-select: the selected tab opens by itself after a few seconds, and a line shows the time left. Off by default.
  • Auto-select time, under Auto-select and only while it is on: how many seconds Auto-select waits, from 1 to 10, 3 by default.

Tab details

  • Show pinned tabs: when off, the switcher leaves out pinned tabs, except the one you are on. On by default.
  • Pinned tab icon: on by default.
  • Playing audio icon: on by default.
  • Inactive tabs: tabs the browser has unloaded to save memory get an icon and are shown in grey. On by default.
  • Tab group color: on by default.
  • Last used: how long ago you used each tab, like “15 min ago”. On by default.
  • Tabs not opened yet: New on the tabs opened in the background, until you open them. On by default. See Tab details.
  • Copy address button: a button on the tab under the mouse that copies its address. On by default.
  • Website address: the page's address on each tab. On by default. Under it, only while it is on:
    • Full address: the whole address of the page, like github.com/giuvincenzi/better-tab-switcher, or, when off, only the site, like github.com. On by default.
    • Long website addresses: Scroll on the selected tab and on the one under the mouse to show them whole (the default), or Cut short with “…”.

Keyboard shortcuts

This section shows the keys for Next tab (Alt+S by default, Control+S on a Mac), Previous tab (Alt+Shift+S, Control+Shift+S on a Mac) and Toolbar icon, which opens the switcher like a click on the toolbar icon (no keys by default). When a shortcut has no keys, it says Not set, and when Next tab or Previous tab has none, a warning above them asks you to choose your own. The Change shortcut button opens the browser's page where you change them: see Change the keys. The How to use Ctrl+Tab link opens Use Ctrl+Tab.

System

Under Restart Better Tab Switcher, the Restart button starts Better Tab Switcher again, as when you turn it off and on in the browser's extensions page. The settings page closes.

Under Restore default settings, the Restore button puts every setting back to its default at once, after you confirm it. It doesn't change your keyboard shortcuts, which the browser manages.

About

The last section shows the version of Better Tab Switcher you have installed.

The browser checks for a new version by itself every few hours, and installs it. Check for updates asks it to check now. It says whether Better Tab Switcher is up to date, or that a new version is ready: then the button becomes Restart extension, which restarts Better Tab Switcher with it, as Restart in System does, and closes the settings page. Without restarting, the browser installs it by itself a little later. When the browser has just checked, it says to try again in a few minutes.

The links under it open, in a new tab:

  • What's new: the release notes of your version, on GitHub.
  • User guide: this guide.
  • Report an issue: the page on GitHub where you report a bug or suggest an idea.
  • Website: Better Tab Switcher's website.
  • Rate this extension: Better Tab Switcher's page on the Chrome Web Store, or on Microsoft Edge Add-ons in Microsoft Edge, where you can write a review.
  • Star on GitHub: Better Tab Switcher's project on GitHub, where you can give it a star.
