# Better Tab Switcher

Tab switcher for Chrome and Microsoft Edge (Manifest V3 extension).

The rules are in `.claude/rules/`, one topic per file:

- `working-rules.md`: how Claude works with the user on this project
- `git-workflow.md`: how every change is made in git and reaches `main`
- `build-and-release.md`: how the extension is built and released
- `testing.md`: which tests the project has and when they run
- `docs.md`: how the website, the user guide and the README are written
- `discoverability.md`: how people find Better Tab Switcher on search engines
- `i18n.md`: how the extension and the website are translated
- `architecture.md`: how the extension's code is organized
- `data.md`: where user data is saved and how it stays compatible between versions
- `ui.md`: how the extension's pages must look

When a rule file is added, removed or renamed, update this list.
